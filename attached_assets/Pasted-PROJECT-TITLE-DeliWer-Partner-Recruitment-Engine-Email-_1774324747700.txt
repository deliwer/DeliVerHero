PROJECT TITLE
DeliWer Partner Recruitment Engine (Email Automation via /marketing)

---

OBJECTIVE

Build a **Vercel-hosted static + serverless hybrid system** where:

* Founders upload broker lists
* System generates personalized partner links
* Emails are sent one-by-one via SendGrid
* All activity is tracked and visible in `/marketing`

This is the **primary growth engine to recruit brokers as partners at scale with zero capital marketing**.

---

# 🧠 SYSTEM OVERVIEW

FRONTEND (Vercel Static)

→ /marketing (command center)
→ /marketing/recruit (email engine UI)
→ /marketing/dashboard (results + tracking)

BACKEND (Serverless API via Vercel Functions)

→ /api/send-email
→ /api/process-brokers

DATA STORAGE

→ Google Sheets (campaign tracking)

---

# 📁 FEATURE 1: BROKER UPLOAD SYSTEM

Page:

/marketing/recruit

UI:

* Upload Excel file (.xlsx)

Expected columns:

Name
Email
Phone
License

# 🔗 FEATURE 2: REFERRAL LINK GENERATOR

For each broker:

Generate:

https://www.deliwer.com/broker-partner?ref={unique_id}&utm_source=brokerlist&utm_campaign=uae_recruit

Logic:

* Extract email prefix OR sanitize name
* Remove special characters
* Ensure uniqueness

Example:

[ahmed.khan@gmail.com](mailto:ahmed.khan@gmail.com) → ref=ahmedkhan

# 🔁 FEATURE 5: CAMPAIGN PROCESSOR

Create:

/api/process-brokers.js

Logic:

* Receive uploaded broker list
* Loop through entries
* Generate referral link
* Call /api/send-email for each
* Wait 1–2 seconds between sends

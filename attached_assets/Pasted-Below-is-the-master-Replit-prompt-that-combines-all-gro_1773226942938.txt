# 3. REFERRAL CAPTURE SCRIPT

Capture parameters and store for **30 days**.

Example:

```javascript
const params = new URLSearchParams(window.location.search);

const referral = {
 partner: params.get("ref"),
 agent: params.get("agent"),
 campaign: params.get("campaign"),
 timestamp: new Date().toISOString()
};

if(referral.partner){
 if(!localStorage.getItem("deliwer_ref")){
   localStorage.setItem("deliwer_ref", JSON.stringify(referral));
 }
}
```

Rules:

* first referral wins
* referral cannot be overwritten
* persists across pages

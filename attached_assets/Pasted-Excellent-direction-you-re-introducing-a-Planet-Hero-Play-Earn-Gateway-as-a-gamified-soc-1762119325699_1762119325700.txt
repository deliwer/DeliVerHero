## ⚙️ Technical Setup (Replit Core Deployment)

Below is a ready **prompt for Replit** to implement and deploy this gateway (without changing the core homepage).

---

### 🧠 Replit Prompt

```yaml
# Replit Prompt: Create Planet Hero - Play & Earn Gateway (DeliWer.com)
# Goal: Add a separate gamified entry system for affiliates & eco missions
# without altering the main homepage structure.

project:
  name: deliwer-planet-hero-gateway
  stack: node-react-express
  integrations:
    - stripe
    - supabase (for user auth, points ledger, missions tracking)
    - emailjs (for notifications)
  deployment: replit-core

tasks:
  - Create a new route group `/planet-hero` in the frontend with pages:
      • index.tsx – Overview page (Play & Earn entry)
      • missions.tsx – List of eco-missions
      • affiliates.tsx – Affiliate signup + referral link dashboard
      • leaderboard.tsx – Weekly top users
      • rewards.tsx – Redeem points
      • manual.tsx – Unified guide (markdown friendly)

  - Add navigation link or banner entry on DeliWer.com home:
      text: "🌱 Planet Hero – Play & Earn"
      link: "/planet-hero"
      position: below AquaCafe section or top navbar (non-intrusive)

  - Implement Supabase tables:
      users: id, name, email, type (‘affiliate’|‘player’)
      missions: id, title, points, proof_type, status
      submissions: user_id, mission_id, proof_link, verified(bool)
      referrals: user_id, referral_code, referred_user_id, reward_points
      rewards: id, title, cost_points, reward_type

  - Integrate Stripe/PayPal reward redemption via DeliWer checkout API.

  - Add point logic middleware:
      onMissionComplete() -> add points to user wallet
      onReferralVerified() -> add bonus points

  - Create `PlanetHeroManual.md` explaining the system:
      sections:
        1. Introduction to Planet Hero
        2. How to Join
        3. Earning Methods
        4. Redeeming Points
        5. Code of Conduct & Eco Ethics

  - Style to match DeliWer’s brand:
      primary_color: #00A4A6
      accent_color: #FFD700
      font: 'Lato'
      theme: light / minimal, with eco-icons (leaf, drop, heart)

  - Ensure responsive design (mobile-first).

  - Deploy gateway under `/planet-hero` subdirectory with SSL enabled.
```

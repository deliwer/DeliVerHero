# 🟢 IMPLEMENTATION DETAILS

## 1️⃣ Create WhatsApp utility

File: /utils/sendWhatsApp.ts

Function:

* Accept phoneNumber (string)
* Accept message (string)
* Call Meta WhatsApp Cloud API
* POST to:
  [https://graph.facebook.com/v17.0/{PHONE_NUMBER_ID}/messages](https://graph.facebook.com/v17.0/{PHONE_NUMBER_ID}/messages)
* Use Bearer WHATSAPP_TOKEN
* Type: text
* Body: message

Handle errors with try/catch and console log failures.

---

## 2️⃣ Create Daily Trigger API

File: /api/daily-founder-trigger/route.ts

GET handler:

* Generate today’s campaign name dynamically.
* Default campaign: movein_week
* Create prewritten outreach message including UTM link.

UTM format:

${BASE_URL}/?utm_source=broker&utm_medium=whatsapp&utm_campaign=movein_week&utm_content=founder

Message format to send to founders:

🚀 DELIWER DAILY OUTREACH TASK

Campaign: Move-In Water + Free Shower Filter

Today’s Action:
Send 25 WhatsApp messages to brokers.

Copy & Send:

Hi [Name] 👋
We’re prioritising Move-In water setup this week.

Please share this link with tenants moving:
[INSERT UTM LINK]

Every booking earns commission automatically.

Reply DONE when completed.

After building the message:

* Parse FOUNDER_NUMBERS env variable (comma separated)
* Loop and send message to each number
* Return JSON { status: "sent" }

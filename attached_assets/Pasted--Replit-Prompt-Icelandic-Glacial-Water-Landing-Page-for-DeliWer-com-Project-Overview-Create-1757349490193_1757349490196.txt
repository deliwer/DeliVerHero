# Replit Prompt: Icelandic Glacial Water Landing Page for DeliWer.com

## Project Overview
Create a premium landing page for Icelandic Glacial Water product line for DeliWer.com, a premium water sustainability company. The page should showcase the complete product catalog with individual product listings for each capacity, emphasizing sustainability, purity, and premium quality.

## Brand Identity & Core Values
- **Source**: Legendary Ölfus Spring, Iceland - one of the world's most pristine ecosystems
- **Purity**: Exceptionally pure and naturally alkaline water with pH of 8.4
- **Sustainability**: World's first bottled water certified CarbonNeutral™ for both product and operation
- **Quality**: Multi-award winning, recognized by leading chefs and sommeliers
- **Heritage**: Filtered slowly for 5,000 years through layers of lava rock
- **Mineral Content**: Naturally low mineral content (TDS of 62ppm)

### Vercel Configuration (vercel.json)
```json
{
  "version": 2,
  "builds": [
    {
      "src": "package.json",
      "use": "@vercel/static-build",
      "config": {
        "distDir": "build"
      }
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/index.html"
    }
  ],
  "headers": [
    {
      "source": "/images/(.*)",
      "headers": [
        {
          "key": "Cache-Control",
          "value": "public, max-age=31536000, immutable"
        }
      ]
    }
  ]
}
```

# 🚀 REPLIT PROMPT — DELIWER BROKER HUB (v1)

**Build a web app called: “DeliWer Broker Hub”**

## 🎯 Objective

Create a broker-facing dashboard for the DeliWer ecosystem that allows registered brokers to:

* Discover rental & commercial opportunities
* Receive AI-guided earning suggestions
* Track referrals and commissions
* Engage with leads provided by the founder/admin system

This is NOT a marketplace like Property Finder.
It is a **controlled opportunity distribution + broker activation system**.

Founder/admin dashboard is NOT included and must remain private.

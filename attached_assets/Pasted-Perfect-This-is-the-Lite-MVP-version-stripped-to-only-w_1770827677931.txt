## 🧠 AGENT SETUP (SIMPLIFIED)

Build **3 lightweight agents** (Agent 4 is manual for MVP).

---

## 🧠 AGENT 1 — EJARI INTENT QUALIFIER

### Trigger

* Incoming WhatsApp message
* Instagram DM
* Manual test input

### First Message (exact)

```
Congrats on your Ejari 🎉  
When are you moving in?
1️⃣ Within 7 days  
2️⃣ 7–14 days  
3️⃣ Later
```

### Capture

* Move-in timing
* Area (free text)
* Apartment or villa

### Rule

* If no reply in 6 hours → send 1 reminder
* On reply → pass data to Agent 2

---

## 🧠 AGENT 2 — MOVE-IN CHECK BOT

### Purpose

Identify **only urgent, sellable problems**.

### Ask max 3 questions, one at a time:

1. “Have you checked the water taste or shower yet?”
2. “Do you need deep cleaning before furniture arrives?”
3. “Any small fixes needed before move-in (lights, curtains, hooks)?”

### Output

Create a simple object:

```json
{
  "water": true,
  "cleaning": false,
  "fixes": true
}
```

Pass this to Agent 3.

---

## 🧠 AGENT 3 — QUICK BUNDLE OFFER

### Rule

Offer **ONE bundle only**.

### Example Logic

* If water OR cleaning = true → offer Ejari Starter Pack
* Otherwise → offer Basic Move-In Help

### Message Template

```
Most tenants with a fresh Ejari do this before moving in:

✅ Ejari Starter Pack
• Water setup + shower filter
• Pre-move deep cleaning

This avoids issues in your first week.

Want me to book this before your move-in?
```

### Outcomes

* “Yes” → mark as READY_FOR_HUMAN
* Question / hesitation → READY_FOR_HUMAN
* No reply → one follow-up only

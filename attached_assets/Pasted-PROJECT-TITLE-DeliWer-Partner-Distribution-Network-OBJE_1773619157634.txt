PROJECT TITLE
DeliWer Partner Distribution Network

OBJECTIVE
Build a partner distribution system for deliwer.com that allows real estate brokers, typing centers, building concierges, and influencers to refer relocation customers using simple referral links.

The system must work on a static site without requiring a database.

Partners will share referral URLs that automatically attach their code to relocation inquiries.

PARTNER TYPES

The system should support these partner categories:

Real estate brokers
Ejari typing centers
Building security desks
Moving companies
Influencers
Corporate relocation teams

Each partner receives a unique referral code.

Example referral link:

/move?ref=partnercode

REFERRAL CAPTURE SYSTEM

Implement JavaScript that detects the referral parameter in the URL.

Example:

deliwer.com/move?ref=broker123

When detected, the referral code should be stored in local storage for the user session.

When the user submits any relocation form or clicks WhatsApp contact, the referral code must automatically be appended to the message.

Example WhatsApp message sent to DeliWer:

“Relocation request
Referral source: broker123
Moving from: Dubai Marina
Moving to: JVC
Move date: 10 May”
